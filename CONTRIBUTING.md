# Contributing

Thanks for helping. This is a small, single-purpose template, so please:

1. Open an issue first, describing the problem or idea, before sending a pull request.
2. Keep Follow-Through chat-only and owner-only. Changes that message other people, score anyone, or act without approval won't be merged.
3. Use only synthetic data (the fictional Alex and Casey fixtures) in tests, issues, and examples. Never paste a real record.
4. If you change `bot-instructions.md`, rerun `tests/regression.md` and `tests/probes.md` (see `docs/TESTING.md`) and add a CHANGELOG entry.
