# Security

Follow-Through needs no API keys and connects to no accounts by default. Its record is a local file under `~/follow-through/<bot id>/`.

To report a security or privacy problem (for example, a way untrusted calendar or web text could make the bot act, or a way it could message someone other than its owner), please don't open a public issue. Use GitHub's private reporting instead: **Security > Report a vulnerability** on this repo.
